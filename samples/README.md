# Sample meal photos

These power the "try a sample" row in the app so a demo is instant and you
don't need a photo of your own to test the pipeline.

They are drawn from the Food-101 validation set (CC-licensed imagery) purely
for demonstration. Replace them with your own photos any time — drop
`.jpg` / `.png` files here and they show up automatically.

To fetch more benchmark images:

```bash
python -m scripts.fetch_eval_set --per-class 1
```
